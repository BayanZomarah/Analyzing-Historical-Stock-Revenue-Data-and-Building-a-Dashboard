# compliance_phases

`compliance_phases` is a Python package scaffold. It exposes a version string and is ready for development with pytest and Ruff. It does not include application features yet.

Requires Python 3.12 or newer.

## Install in editable mode

From the repository root, with your virtual environment activated:

```bash
python -m pip install -e ".[dev]"
```

The `dev` extra installs pytest and Ruff.

## Tests

```bash
pytest
```

## Lint

```bash
ruff check .
```
